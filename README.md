# 빅콘테스트 2026 프로젝트

사회적 고립 예방 및 대응을 위한 AI 에이전트 개발을 주제로, 통신 유동인구와 카드 집계 데이터를 검토하고 분석·서비스 방향을 설계하는 프로젝트다. 현재 자료와 분석은 지역·인구집단 단위의 활동 특징을 다루며, 개인의 실제 고립 상태를 확정하는 결과로 해석하지 않는다.

## 연구 방향

- 제공 데이터를 통해 지역·인구집단 단위의 활동 특징을 검토한다.
- 사회적 고립과 지원서비스 이용 장벽에 관한 문헌 근거를 조사한다.
- 분석과 연구 근거를 바탕으로 필요한 지원과 대응 방안을 연결하는 AI 에이전트를 설계한다.

## 현재 단계

문제 정의, 제공 자료 검토와 분석 방향을 구체화하는 단계다. 최종 모델과 사회적 효과의 검증은 후속 작업으로 진행한다.

## 최초 공개 범위

최초 공개 범위는 이 프로젝트 소개다. 제공 원자료, 분석 코드·보고서·중간 산출물, 관리 안내와 에이전트 인계 문서는 로컬에서 관리한다.
