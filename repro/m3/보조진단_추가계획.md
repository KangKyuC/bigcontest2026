# 첫 적합 뒤 보조 진단 기록

2026-10-22. 최초 실행에서는 수축 단일 Gaussian이 선택됐다. 동별 보류에서 SK 추가가 소폭 악화됐지만 5개 공간 블록에서는 개선돼, 분할 방식에 대한 불확실성이 생겼다. 주 모델 선택 규칙과 주 비교를 변경하지 않는다.

1. K=1의 ARI=1과 소속확률=1은 자명한 값이다. 유형 안정성 근거로 보고하지 않고 해당없음으로 표시한다. 대신 연속 특성의 순위·관측창 민감도와 모델 밀도의 OOB 변동을 기록한다.
2. 원래 후보표 안에서 보류 평균점수가 가장 높은 다성분 GMM에 동 부트스트랩 200회를 적용한다. 이 결과는 실패한 유형 후보의 진단용이며 주 모델을 다시 선택하는 근거로 쓰지 않는다. K-means의 2분할 안정성과도 구별한다.
3. 공간 분할의 4/6블록 보조 평가와 22동 평균 예측잔차의 공간 유사성을 확인한다. 이는 첫 결과를 본 뒤 추가한 탐색 진단이다. 유리한 공간 분할만 본문 결론으로 올리거나 22동 주 결과를 대체하지 않는다.
4. 단일 Gaussian의 위치·공분산 적합과 유형 분할의 타당성은 다른 질문이다. 연속적인 특성이 재현 가능하더라도 자연적으로 나뉜 주민 유형이나 고립 위험이 검증된 것은 아니다.
