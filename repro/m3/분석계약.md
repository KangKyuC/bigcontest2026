# M3 제작·검증 계약

2026-10-22. 새 M3 모델을 학습하기 전에 기록한 실행 규칙이다. 기존 분석과 데이터 내용을 이미 보았으므로 외부 사전등록 또는 맹검 연구라고 주장하지 않는다. 원본 데이터와 기존 분석은 수정하지 않는다.

## 측정과 범위

- 강남 22동 × 성별2 × 성인 연령5(20/30/40/50/60+)가 기본 단위다. 행은 개인이 아니다. 인구수를 독립 표본 수나 군집 가중치로 사용하지 않는다.
- 서울 2025-10 파일의 연락·외출은 2025-07~09 SK와 맞춘다. 2025-12 파일은 09~11 SK와 다시 맞춘다. 기존 440행 표에는 두 창 모두 07~09 SK가 붙어 있어 그대로 모델 입력으로 사용하지 않는다.
- 공통 6개월 관측 지점은 기존 감사의 고정된 측정망을 재사용한다. 회고적 비교를 위한 표본이며 실제 미래 조기탐지 평가가 아니다. 원시 SK와 점별 키를 다시 대조한다.
- 5세층을 동일 가중으로 평균한 비교 지수다. 인구 가중치는 근사 정의의 민감도이며 정확한 개인 평균이라고 부르지 않는다. 사분위수를 평균하지 않는다.
- 연락은 전화번호 수이며 관계의 질, 도울 수 있는 사람 수가 아니다. 통신과 SK는 같은 사업자 계열 자료라 독립 측정 검증이 아니다.
- 근무·출근, SNS, 추정 관심집단·1인가구수는 주 학습에서 제외한다. 기간 불일치·정의·순환성 문제를 피한다. 문자 대상자는 보조 민감도로 남긴다.

## 입력과 전처리

핵심 6변수: 통화대상자 지수, 평일 이동, 휴일 이동, 공통 관측점당 유동, 점별 유동 집중도(N×HHI), 창 시작~끝 월의 log1p 유동 차이. 집중도는 관측 지점 사이의 분포이며 주민의 활동반경이 아니다. 유동량은 각 월의 일수로 가중한다. 변화는 세 달 경로의 한 요약이며 추세 예측이 아니다.

양의 수준 변수에 log1p를 적용한다. 연락·외출의 동년배 중심은 강남을 제외한 서울 402동에서 정한다. SK는 각 학습 폴드의 동×성·연령으로만 중심을 정한다. 척도·블록 가중도 학습 자료에서 고정한다. 1개 연락, 2개 외출, 3개 SK 변수에 블록 크기의 제곱근 역수를 곱해 K-means 거리의 기여를 맞춘다. GMM에서는 공분산도 추정하므로 이 척도 조정만으로 블록의 우도 기여가 균등해지지는 않는다. GMM의 블록 의존성은 블록 제거·대체 정의·유형별 기여로 별도 확인한다. 원값과 동년배 위치는 모두 출력한다.

결측/비공개를 0으로 바꾸지 않는다. 주 변수에서 결측이면 해당 셀은 학습 보류다. 이동 미추정 비율 20% 초과는 품질 주의, 50% 초과는 제외한다. 이 수치는 운영상 품질 규칙이며 임상/고립의 검증된 경계가 아니다. 20% 이하 셀만 사용한 민감도도 확인한다.

## 비교 모형과 선택

- 연속 연락·외출 프로필, K=1 기준, K-means K=2~5, 대각 GMM K=1~5를 비교한다.
- 상관된 두 이동 변수를 여러 군집으로 억지 근사하는 것을 점검하기 위해 수축 공분산을 쓰는 단일 Gaussian(Ledoit-Wolf)을 추가 기준으로 둔다.
- 최종 유형 후보의 K는 같은 입력 공간 안에서 동 묶음 5-fold 보류 로그밀도를 비교하고 1-SE 규칙으로 단순한 후보를 택한다. BIC와 silhouette는 보조값이다. 다른 입력 차원끼리 원시 우도/BIC를 비교하지 않는다.
- 22회 동별 보류 바깥에서, 각 학습셋 안의 5-fold로 후보 선택을 다시 수행한다(중첩 평가). 가까운 동을 묶은 5개 공간 블록 평가를 별도로 시행한다. 공간 블록은 관측점 중심좌표로 생성한 근접 그룹이며 공식 생활권이 아니다.
- 전처리의 선형 척도 변환에 따른 Jacobian을 로그밀도에 반영해 폴드별 점수의 기준을 맞춘다. 이 밀도는 변환된 특성 벡터의 밀도이며 고립 확률이 아니다.

## 안정성과 채택

동 단위 부트스트랩 200회, 각 회차에서 전처리와 고정 K 모형을 다시 적합한다. 주 안정성은 표집되지 않은 동(OOB)의 ARI다. 군집명 정렬은 그 회차의 학습 동에서만 한다. 셀별 OOB 배정 일치도와 빈도도 남긴다. 전체 자료 재배정 ARI는 보조 진단이다.

유형을 확정해 외부에 내보내려면: K>1, 중첩 보류에서 단일 수축 Gaussian보다 로그밀도 향상이 확인됨, OOB ARI 중앙값≥0.75 및 하위10%≥0.5, 각 유형에 5셀·3동 이상이 있어야 한다. 이 기준은 운영상 보수적 채택 규칙이며 보편적 통계 정리가 아니다. 실패하면 연속 프로필을 주 산출물로 제공하고 군집은 탐색 결과로만 보존한다.

연령 보정 제거, 표준/강건 척도, 문자 추가, 변수 하나씩 제거, 인구 가중 근사, 이동거리 대체, 낮은 미추정 셀, 12월 창을 민감도로 평가한다. 모든 대안 결과를 보존하며 유리한 정의로 주 분석을 갈아끼우지 않는다.

## 제공 데이터 추가 가치

연락·외출만, SK만, 결합 모형을 같은 셀에서 비교하되 차원별 점수를 직접 비교하지 않는다. 별도 평가 과제의 목표는 통화대상자 지수다. 인구집단만, 인구집단+외출, 인구집단+외출+SK의 Ridge 모형을 같은 동 보류 셀에서 비교한다. 목표를 직접 또는 문자/SNS로 우회 입력하지 않는다. Ridge 계수도 학습 내부의 동 분할로 선택한다.

주 비교는 외출 기준 대비 SK 추가의 MAE 차이다. 동별 짝지은 오차와 동 재표집 구간을 제시한다. 이 구간은 고정된 OOF 예측 오차를 재표집한 근사 구간이며 전체 학습 불확실성을 포함하는 임상적 신뢰구간이 아니다. 인접 동 의존성은 공간 블록 평가로 추가 점검한다. 여러 보조 비교를 확증적 유의성으로 해석하지 않는다.

카드는 원래 시군구×성·연령 단위로만 설명 자료에 연결한다. 춘천 업종 공통 감소 등 반례를 보존한다. 통신 변수 변화가 정책 자격을 변경하지 않는다.

## 출력과 검수

학습된 모델과 전처리, 입력 440셀, 기준모형·중첩평가·안정성·민감도 결과, 220셀 프로필, 보류/불확실성, 설명 가능한 근거, 정책 모듈 전달 JSON, 실행 코드·출처·환경·보고서를 제공한다. 실제 개인 고립 정답 검증·정책효과·지원수요는 이 모델의 성능으로 주장하지 않는다.

직렬화 재현, 원본 집계 일치, 관측창 분리, 폴드 겹침 방지, 결측·미지원 입력 거절, 확률합, 블록별 설명 합산, 프로필-정책 가정 구분을 검사한다.

방법 참고: scikit-learn 1.6.1의 Gaussian mixture, grouped/nested cross-validation, clustering, covariance estimation 공식 문서. 실제 설치 버전과 코드로 동작을 검증한다.
