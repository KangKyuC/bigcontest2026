# 이음 대시보드 화면 구성

이 문서는 현재 공개한 `src/agent/` 화면을 설명합니다. 실제 빌드의 [전체 화면](../docs/figures/dashboard_overview.png)과 [실행 안내](README.md)를 함께 볼 수 있습니다.

## 화면의 역할

- 지도는 행정동별 가상 사례와 선택한 사례의 지원 장소를 표시합니다. 위치는 동 중심점·근사 기관 위치이며 개인 주소를 표시하지 않습니다.
- 상단에서 강남구·춘천시를 전환하고 설정 창에서 배경 지도·경계·연결선 표시를 고릅니다.
- 왼쪽 브리핑에서 동별 목록·대표 사례·정책 추천을 전환합니다. 집계 신호·가상 가정·조사 시점을 화면에 함께 표시합니다.
- 사례를 선택하면 데스크톱에서는 오른쪽, 모바일에서는 하단 상세 창이 열립니다. 검토 단계·근거·조건 충돌·대안·보완 시나리오를 확인할 수 있습니다.
- 정책 추천을 선택하면 해당하는 가상 사례 수·동·변경 조건·출처를 표시합니다. 사례 수를 실제 주민 수로 표현하지 않습니다.

## 토큰과 색

`src/tokens.css`의 원래 색상 값 → 의미 토큰 → 컴포넌트 역할 순서로 스타일을 구성합니다. 화면별 배치와 반응형 규칙은 `src/agent/agent.css`에 있습니다.

| 역할 | 표현 |
| --- | --- |
| 주요 행동·선택 | 파랑, 선택 테두리·버튼·연결할 장소 |
| 검토 단계 | 1 긴급·2 높음·3 주의·4 관찰의 글자와 색을 함께 표시 |
| 이용조건 | 이용 가능·심사·확인 필요·충돌을 문구와 함께 표시 |
| 지도 | 경계·동별 배지·대표 사례 핀·선택한 지원 장소를 분리 |

단계는 사전에 정한 검토 순서이며 개인 고립 확률을 나타내지 않습니다. 동 색은 그 동의 가상 사례에서 가장 높은 검토 단계에 대응합니다.

## 글꼴과 조작

배포 가능한 Pretendard Variable을 저장소에 포함하고 한글·숫자에 사용합니다. 없는 글꼴을 네트워크에서 요청하지 않습니다. 숫자는 일정한 폭을 사용합니다.

지역·목록 전환에는 탭 역할과 선택 상태를, 지도·분석 창·닫기·설정 버튼에는 이름을 제공합니다. 동작을 줄이도록 설정한 환경에서는 애니메이션을 줄입니다. 공개 빌드는 데스크톱 1440×960과 모바일 390×844에서 확인했습니다. 전체 접근성 인증을 수행했다는 뜻은 아닙니다.

Button·Switch·Dialog 등은 [제3자 고지](THIRD_PARTY_NOTICES.md)에 출처와 이용조건을 보존했습니다. 저장소에 남은 공통 UI 컴포넌트가 모두 현재 화면에서 사용되는 것은 아닙니다.

배경 지도는 OpenStreetMap이며 출처 표시를 유지합니다. 지도 타일에는 인터넷 연결이 필요합니다. 정책 스냅샷과 경계·근사 좌표는 공개 정적 파일에서 읽습니다.
