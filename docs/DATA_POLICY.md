# 데이터 출처·결합·공개 범위

이 GitHub 저장소는 공개 저장소입니다. 분석 방법과 성능을 검토할 수 있도록 코드·고정 설정·원본 지문·집계 성능표·결과 도표를 공개합니다. 원자료 재배포와 분석 공개를 구분합니다.

## 입력 자료

| 자료 | 제공자·출처 | 범위 | 확보·배포 방식 |
| --- | --- | --- | --- |
| 성·연령별 소지역 유동 | 빅콘테스트 제공 SK 자료 | 강남·춘천, 2025-07~12, 월별 CSV 6개 | 공식 대회 권한으로 별도 확보, 원본 공개하지 않음 |
| 카드 업종별 결제 데이터2 | 빅콘테스트 제공 신한카드 자료 | 두 지역 가맹점, 2025-07~12 | 선택 서술 EDA에만 사용, 원본 공개하지 않음 |
| 행정동단위 29개 통신정보 | [서울특별시 열린데이터광장](https://data.seoul.go.kr/dataList/OA-22267/F/1/datasetView.do) | 2025-10·2025-12 XLSX | 공식 서버 다운로드 코드 제공, 공공누리 1유형 출처 표시 |
| 강남 22동 코드 대응표 | 서울 제공 코드표·연구에서 대조한 행정동 코드 | 서울 7자리·통계 8자리·행정 코드 | [대응표](../repro/m3/assets/gangnam_dong_codes.csv) 포함 |

정확한 파일명·바이트 크기·SHA-256·공개 다운로드 요청은 [sources.json](../data/sources.json)에 있습니다. 원본 지문이 다르면 자동 대체하지 않습니다. 대회에서 외부 자료를 제출할 수 있다는 조건을, 제공 SK·카드 자료를 공개 GitHub에 재배포할 수 있다는 허가로 해석하지 않았습니다.

데이터 권리는 각 제공기관의 조건을 따릅니다. 공개 데이터 출처 표시를 경쟁 데이터의 이용 허가로 확대하지 않습니다. 코드에도 별도 오픈소스 라이선스를 임의로 부여하지 않았습니다.

## 공개한 것

- 전처리·모델 선택·중첩 평가·안정성·추론·재현 비교 코드.
- 통계 설정·학습 전 계약·사후 진단 계획·코드 유래 지문.
- 후보별 보류 점수, 보조 예측 성능, 안정성·민감도 요약과 해석.
- 같은 성·연령의 서울 비교위치 등 공개 행동자료로 설명하는 사례.

## 로컬에 남기는 것

- 대회 원 CSV·TXT·ZIP·레이아웃·주제설명서 PDF.
- 외부 원본 XLSX·원 자료실·팀 회의록·인계 문서.
- 공통 관측점 좌표·원 5세층·220셀 결합 입력·행별 예측·OOF 기록·정책 인계 JSON.
- 학습 `joblib`과 행별 보고서·결과 Excel. 이들은 권한 있는 원본으로 로컬 재생성합니다.
- 인증정보·가상환경·캐시·DuckDB·로그.

원본 없이 모델의 모든 수치를 재계산할 수 있는 저장소는 아닙니다. 코드와 원본 식별자를 고정해, 권한 있는 사람이 같은 자료로 모델과 수치를 복원할 수 있게 구성했습니다. 생성 경로는 `.gitignore`로 제외합니다.

## 결합 규칙

| 차원 | 허용한 연결 | 금지한 해석 |
| --- | --- | --- |
| 서울 행동 | 행정동·성·연령·관측창 | 행 평균을 개인의 상태로 추정 |
| SK 소지역 유동 | 코드·좌표 공통점 → 동·성·연령·관측창 | 방문·통행을 주민 수요로 간주 |
| 카드 | 가맹점 시군구·성·연령·월 | 가맹점 위치를 고객 거주동으로 배정 |
| 정책 | 별도 지원 필요·정확한 이용조건·정책 회차 | 집계 연락·유동으로 자격·희망을 생성 |

서울 2025-10은 7~9월, 2025-12는 9~11월 유동과 연결합니다. 6개월 공통점은 회고적으로 고정한 측정망이므로 미래 탐지 검증에서 사용할 수 있는 사전 측정망과 다릅니다. 춘천에 서울 행동값을 복사하지 않습니다.

일원2동→개포3동 명칭은 코드 대응표에 보존했습니다. 현재 경계와 이름을 새 원본에 자동 적용하지 않으며, 새 버전에서는 다시 감사해야 합니다.

## 추가 원자료·제약

MDIS 국가 사회조사 등은 후보 검토에 등장했지만 M3의 고립 정답으로 사용하지 않았습니다. 원자료 확보·지리키·대표성이 맞지 않은 자료를 결합 정답처럼 취급하지 않습니다. 시간 부족·정보 부족이라는 평생교육 설문 결과도 고립 지원사업의 실제 미이용 원인 비율로 일반화하지 않습니다.
