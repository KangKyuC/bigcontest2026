공개 웹사이트는 별도 배포의 스냅샷입니다. 이 제출본과 정확히 같은 코드·문구를 확인하려면 저장소의 대시보드를 로컬에서 실행합니다. 공개 데이터 세 파일의 지문은 [스냅샷 명세](../dashboard/snapshot-manifest.json)에 있습니다.

## 실제 구현한 범위

- **대시보드:** React·TypeScript·Leaflet 지도, 강남·춘천 전환, 동별 70개·대표 5개 가상 사례, 지원사업 54개에 대한 조건 대조와 보완 시나리오.
- **규칙 기반 에이전트:** 이용조건을 충족·충돌·심사·미확인으로 나누고 검토 순서·설명·추천을 정해진 규칙으로 생성합니다. 생성형 언어모델을 호출하지 않습니다.
- **M3:** 강남 22동 × 성별 2 × 성인 연령 5의 220셀에 대한 원본 재집계·모형 비교·중첩 평가·안정성·민감도·별도 연락 지수 예측.
- **제출 검증:** 공개 코드·정책 규칙·서버 보안·정적 스냅샷 시험, 지원 Python 환경에서의 실제 모델 재현, 대시보드 빌드·브라우저 점검, 의존성·비밀정보 검사.

## 실행 환경

대시보드는 Node.js 24와 npm으로 실행합니다. 공개 스냅샷이 있어 대회 원자료·API 키·Python 서버가 필요하지 않습니다.

```sh
npm --prefix dashboard ci --ignore-scripts
npm --prefix dashboard run dev
```

M3의 권장 재현 환경은 Python 3.11입니다. 전체 환경은 배포 파일의 해시까지 고정했습니다.

```sh
python -m pip install --require-hashes -r requirements-lock-py311.txt
python repro/m3/verify_sources.py
python repro/run.py
```

M3 전체 재현에는 권한 있는 SK 원본과 공개 서울 원본이 필요합니다. 스냅샷을 처음부터 다시 만드는 정책 파이프라인은 공개하지 않은 조사 입력도 필요합니다. [데이터 배치 안내](REPRODUCE.md)와 [대시보드 입력 목록](../dashboard/README.md)을 따릅니다.

## 결과를 설명할 때의 경계

대시보드의 75개는 실제 주민 수가 아니며, 1~4단계는 개인 고립 확률이나 학습 모형의 위험 등급이 아닙니다. M3가 선택한 수축 단일 Gaussian은 확정적인 고립 유형을 만들지 못했습니다. 연락·외출 관측 백분위와 SK 장소 맥락, 가정한 가구·시간 조건을 구분합니다.

조건엔진과 화면의 구현은 실제 주민에 대한 자격 판정·정책 수요·현장 효과 검증을 뜻하지 않습니다. B0~B3 정보 추가 비교와 정책 기여에 관한 독립 평가는 [후속 검증](PROJECT_STATUS.md)에 남아 있습니다. 대회 요구사항 전체 충족이나 정책 개선 효과를 확보했다고 주장하지 않습니다.

원자료·전체 행별 결합 입력·학습 바이너리·내부 문서는 배포하지 않습니다. 코드의 별도 오픈소스 이용 허가는 부여하지 않았고, 데이터·제3자 코드·글꼴의 권리는 각 제공조건을 따릅니다.
