# M3 모델 카드 — 결과와 의미

연구 기준일 2026-10-22. 공개 재현판 정리일 2026-10-25.

## 1. 모델이 추정하는 것

M3는 강남 행정동×성별×성인 연령의 **집계 특성 분포**를 설명합니다. 연락·외출·장소 유동 6변수를 관측하고, 여러 이산 유형으로 분리하는 것이 보류 자료·안정성 기준에서 지지되는지 시험했습니다.

현재 선택은 Ledoit–Wolf 수축 공분산 단일 Gaussian과 연속 프로필입니다. 군집이 채택되지 않았다는 것은 모든 사람이 같은 위험이라는 뜻이 아닙니다. 검토한 입력·후보·규칙 안에서 여러 유형으로 확정할 근거를 확보하지 못했다는 뜻입니다. 모든 가능한 군집 방법의 불가능성을 증명한 것도 아닙니다.

| 출력 | 의미 | 의미하지 않는 것 |
| --- | --- | --- |
| 행동 원값·서울 동년배 비교위치 | 같은 성·연령의 다른 동과 비교한 집계 지수 | 개인 고립·심리 상태 |
| 장소 유동·집중·변화 | 관측점 이용환경 | 거주민 개개인의 동선 |
| `feature_log_density` | 변환 특성 공간의 밀도 | 고립 확률·위험 점수 |
| 미채택 유형의 빈칸 | 확정 유형을 공개하지 않음 | 정보가 없어 모두 정상이라는 판단 |
| 인계 질문 | 추가 확인할 사안 | 지원 필요·자격·정책 공백의 증명 |

## 2. 모집단·측정·기간

- 강남 22동×남녀×20·30·40·50·60세 이상, 220집계셀입니다. 인구수를 독립 표본 수나 군집 가중치로 사용하지 않습니다.
- 행동 변수는 원 5세층의 동일가중 비교 지수입니다. 전체 개인의 정확한 평균이나 합성 개인의 사분위수를 만들지 않습니다.
- 연락은 통화한 번호 수에 관한 지표입니다. 사회적 지지·관계의 질·대면 교류를 직접 측정하지 않습니다.
- 서울 매뉴얼의 이동 추정 한계 때문에 가까운 생활권 이동이 낮게 잡힐 수 있습니다. 가게 밀도·경사·연락 사이 상관을 개인 고립의 인과효과로 바꾸지 않습니다.
- SK는 방문자를 포함한 장소 유동입니다. 카드와 SK, 서울 행동을 동일한 사람의 기록으로 연결하지 않았습니다.
- 주 창은 7~9월, 민감도 창은 9~11월로 겹칩니다. 6개월 공통 관측망도 회고적으로 정하므로 미래 조기탐지 성능이 아닙니다.
- 서울 행동 자료와 제공 SK는 같은 사업자 계열의 추정 자료입니다. 완전히 독립적인 측정 검증이라고 주장하지 않습니다.

## 3. 학습·평가의 방어 장치

강남 외 서울 402동의 같은 성·연령 기준으로 행동을 중심 보정합니다. SK 중심과 강건 척도는 각 학습 폴드 안에서만 적합합니다. 후보 선택도 외부 보류 동을 제외한 내부 동 그룹 5-fold에서 수행합니다.

수축 전체 공분산 기준을 둔 이유는 평일·휴일 이동의 상관을 여러 대각 GMM 성분이 대신 근사하면서 군집처럼 보이는 상황을 점검하기 위해서입니다. 블록별 변수 개수 보정이 GMM에서 블록별 동일 우도 가중을 보장하지는 않습니다.

최종 후보는 수축 1성분, 대각 GMM 1~5성분입니다. 보류 로그밀도와 1-SE 단순화 규칙을 사용합니다. 서로 다른 차원의 모형 간 원시 우도나 BIC를 직접 비교하지 않습니다.

유형 채택 기준은 K>1, 중첩 보류에서 수축 기준보다 개선, 동 OOB ARI 중앙값≥0.75·하위10%≥0.5, 유형당 최소 5셀·3동입니다. 공학적 운영 기준이며 보편적인 임상 척도나 통계 정리는 아닙니다.

## 4. 핵심 결과

| 항목 | 실제 결과 | 해석 |
| --- | --- | --- |
| 선택 모형 | 수축 단일 Gaussian | 다중 위험유형 미채택 |
| GMM3 OOB ARI | 중앙값 0.390·하위10% 0.233 | 확정 페르소나로 쓰기 어려움 |
| K-means2 OOB ARI | 중앙값 0.829·하위10% 0.544 | 안정적 절단 가능성, 자연 유형의 정답 아님 |
| 한 동 보류 SK 추가 MAE | 0.746729→0.771745 | 주 평가에서 개선 확인 못함 |
| 공간5블록 SK 추가 MAE | 0.834588→0.731694 | 분할 방식에 의존한 개선 방향 |

연락 예측은 보조 과제입니다. 성·연령만으로도 R²가 높아 전체 집단 간 차이가 예측을 쉽게 만들 수 있습니다. 따라서 R² 크기를 고립의 설명력으로 제시하지 않고, 같은 보류 셀의 추가 입력 전후 오차를 비교했습니다.

한 동 보류 개선량의 근사 구간은 0을 포함합니다. 공간5블록은 양의 구간이지만 블록 수가 적고, 사후 4·6블록 구간은 0을 포함합니다. 유리한 공간 분할만 골라 확정 결론으로 채택하지 않습니다. 고정 OOF 오차의 재표집 구간은 전체 재학습 불확실성을 포함하지 않습니다.

민감도에서 공통 변수 점수의 순위상관이 1인 항목도 독립적인 모델 타당성 증명이 아닙니다. 단조 변환이나 같은 전처리를 유지했을 때 순서가 그대로인 결과일 수 있습니다. 관측창 최저 상관과 연령 보정 제거 결과를 함께 보존했습니다.

## 5. 의미론적 기여와 아직 빈 부분

연락·외출이 같은 방향으로 움직인다는 가정을 깨고 서로 다른 확인 질문을 만드는 것은 유용합니다. 그러나 현재 대표 사례의 연락·이동 백분위와 조사 질문은 **공개 원자료의 기술통계**로도 만들 수 있습니다. Gaussian의 채택과 기술통계의 유용성은 같은 증거가 아닙니다.

SK는 장소 활동환경을 추가하지만 그것이 정책 조건·조사 우선순위를 개선했는지는 아직 검증하지 않았습니다. 예를 들어 비슷한 연락·외출 집계가 서로 다른 상권 유동을 가질 수 있다는 사실만으로, 특정 지역 주민의 지원 필요나 시간 선호를 추정할 수 없습니다.

현재 달성한 성과는 다음과 같습니다.

1. 관측 단위·기간·주민과 방문자의 차이를 명시한 결합 입력을 복원했습니다.
2. 다양한 유형을 반드시 만들지 않고, 보류 평가와 안정성에 따라 미채택 결정을 보존했습니다.
3. 전체 220셀의 특성과 품질·미확인 조건을 정책팀에 전달할 인터페이스를 만들었습니다.

아직 달성하지 못한 성과는 고립 위험 분류, 실존 고위험 페르소나 발굴, 미충족 수요 규모, 정책 공백의 실증, 지원 효과, 학습 모형의 독립적인 정책 가치입니다.

## 6. 권장 사용과 후속 평가

정책 검토자가 조사 후보의 맥락과 반례를 읽는 보조 자료로 사용합니다. 지원 필요·정확한 나이·가구 형태·소득·가능 시간·참여 의사는 별도로 확인합니다. 활동 관측을 바꿔도 같은 정책·시점·이용자 조건의 자격 판정은 바뀌면 안 됩니다.

다음 평가에서는 같은 사례·같은 판단 목적을 유지하고 B0 정책·인구·조사, B1 공개 행동, B2 제공 SK, B3 학습 모형 순서로 비교합니다. 새로운 그래프나 달라진 순위만 기여로 세지 않고, 원문·반례로 정당화되는 추가 질문·오해 철회·조건 검토를 기록합니다. 실패·정보 부족·대안 존재도 결과로 남깁니다.

프로필이나 군집 이름을 실제 개인에게 배정하거나 지원 선정·제외를 자동화하는 용도에는 검증되지 않았습니다.
