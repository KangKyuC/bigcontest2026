## 운영 범위와 남은 한계

로컬 Python API는 분석용 보조 도구입니다. 인터넷 공개 서버의 인증·권한 체계는 구현하지 않았고 루프백 실행만 허용합니다. 공개 대시보드는 정적 JSON을 읽으며 Python API나 비밀 토큰이 필요하지 않습니다.

`joblib`은 임의 코드를 포함할 수 있으므로 신뢰하는 코드와 원자료로 직접 생성한 모델만 로드합니다. 파일 확장자·파일 지문 검사만으로 타인이 만든 모델을 안전하게 만들 수 없습니다.

브라우저 검사는 저장소에서 만든 빌드에 보안 헤더를 적용해 수행했습니다. 기존 운영 사이트를 새로 배포하거나 그 운영 설정을 감사한 결과가 아닙니다. GitHub 업로드와 라이브 호스팅 배포를 구분합니다.

비공개 정책 조사 입력이 없어 전체 정책 스냅샷 재생성은 이번 검토에서 실행하지 않았습니다. 공개 스냅샷 정합성과 합성 정책 규칙 시험을 수행했습니다. 취약점 0건은 검사 시점의 알려진 데이터베이스·도구·범위에 대한 결과입니다.
